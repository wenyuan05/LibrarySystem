# 图书详情页实现计划

## 任务分解与优先级

### [ ] 任务 1: 修改数据库结构，为 book 表添加新字段
- **优先级**: P0
- **依赖关系**: 无
- **描述**:
  - 在 book 表中添加 publisher（出版社）、publish_date（出版日期）、language（语言）、page_count（页数）等字段
  - 更新数据库初始化脚本，确保新字段被正确创建
- **成功标准**:
  - 数据库结构已更新，包含新的字段
  - 现有数据不受影响
- **测试要求**:
  - `programmatic` TR-1.1: 运行数据库初始化脚本后，book 表应包含新的字段
  - `programmatic` TR-1.2: 现有书籍数据仍可正常访问

### [ ] 任务 2: 修改后端 API，支持新字段的操作
- **优先级**: P0
- **依赖关系**: 任务 1
- **描述**:
  - 修改 bookController.js，更新书籍的创建、更新、获取等方法，支持新字段
  - 修改 bookRoutes.js，确保 API 路由支持新字段
- **成功标准**:
  - API 能够处理包含新字段的书籍数据
  - 所有书籍相关的 API 端点正常工作
- **测试要求**:
  - `programmatic` TR-2.1: 调用创建书籍 API 时可以包含新字段
  - `programmatic` TR-2.2: 调用获取书籍 API 时返回包含新字段的数据

### [ ] 任务 3: 创建书籍详情页组件
- **优先级**: P0
- **依赖关系**: 任务 2
- **描述**:
  - 创建 BookDetailsPage.jsx 组件，用于展示书籍的详细信息
  - 创建 BookDetailsPage.css 文件，为详情页添加样式
  - 实现书籍信息的展示，包括标题、作者、出版社、出版日期等
  - 实现借阅和预约功能的 UI
- **成功标准**:
  - 详情页能够正确展示书籍的所有信息
  - 页面布局美观，响应式设计
- **测试要求**:
  - `human-judgment` TR-3.1: 详情页布局美观，信息展示清晰
  - `programmatic` TR-3.2: 详情页能够正确加载和显示书籍数据

### [ ] 任务 4: 修改前端路由，添加详情页路由
- **优先级**: P1
- **依赖关系**: 任务 3
- **描述**:
  - 修改 App.jsx，添加书籍详情页的路由配置
  - 路由路径应为 `/books/:id`，其中 :id 为书籍的 ID
- **成功标准**:
  - 路由配置正确，能够通过 /books/:id 访问详情页
  - 路由参数能够正确传递给详情页组件
- **测试要求**:
  - `programmatic` TR-4.1: 访问 /books/1 能够正确加载 ID 为 1 的书籍详情
  - `programmatic` TR-4.2: 路由参数能够正确传递给详情页组件

### [ ] 任务 5: 修改书籍列表页面，添加点击跳转功能
- **优先级**: P1
- **依赖关系**: 任务 4
- **描述**:
  - 修改 BookList.jsx 组件，为每本书籍添加点击事件
  - 点击书籍时，跳转到对应的详情页
- **成功标准**:
  - 点击书籍列表中的书籍时，能够跳转到该书籍的详情页
  - 跳转时正确传递书籍 ID
- **测试要求**:
  - `programmatic` TR-5.1: 点击书籍列表中的书籍，能够成功跳转到详情页
  - `programmatic` TR-5.2: 跳转后的详情页显示正确的书籍信息

### [ ] 任务 6: 在详情页中实现借阅和预约功能
- **优先级**: P1
- **依赖关系**: 任务 3
- **描述**:
  - 在详情页中添加借阅按钮，用户点击后可以借阅书籍
  - 添加预约按钮，当书籍不可用时可以预约
  - 实现借阅和预约的 API 调用
  - 添加成功和失败的提示
- **成功标准**:
  - 点击借阅按钮后，能够成功调用借阅 API
  - 点击预约按钮后，能够成功调用预约 API
  - 操作后显示适当的提示信息
- **测试要求**:
  - `programmatic` TR-6.1: 点击借阅按钮，能够成功调用借阅 API
  - `programmatic` TR-6.2: 点击预约按钮，能够成功调用预约 API
  - `human-judgment` TR-6.3: 操作后显示适当的提示信息

### [ ] 任务 7: 更新图书管理页面，支持新字段的编辑
- **优先级**: P2
- **依赖关系**: 任务 2
- **描述**:
  - 修改 AddBookForm.jsx 和 EditBookForm.jsx，添加新字段的表单输入
  - 确保表单能够正确提交包含新字段的数据
- **成功标准**:
  - 图书管理页面能够添加和编辑包含新字段的书籍
  - 表单验证正确，数据提交成功
- **测试要求**:
  - `programmatic` TR-7.1: 能够通过表单添加包含新字段的书籍
  - `programmatic` TR-7.2: 能够通过表单编辑书籍的新字段

### [ ] 任务 8: 测试和优化
- **优先级**: P2
- **依赖关系**: 所有任务
- **描述**:
  - 测试所有功能，确保正常工作
  - 优化页面性能和用户体验
  - 修复可能的 bug
- **成功标准**:
  - 所有功能正常工作
  - 页面加载速度快，用户体验良好
- **测试要求**:
  - `programmatic` TR-8.1: 所有 API 调用正常，无错误
  - `human-judgment` TR-8.2: 页面响应速度快，交互流畅

## 实施顺序

1. 任务 1: 修改数据库结构
2. 任务 2: 修改后端 API
3. 任务 3: 创建书籍详情页组件
4. 任务 4: 修改前端路由
5. 任务 5: 修改书籍列表页面
6. 任务 6: 实现详情页的借阅和预约功能
7. 任务 7: 更新图书管理页面
8. 任务 8: 测试和优化

## 技术要点

- 使用 SQLite 的 ALTER TABLE 语句添加新字段
- 确保后端 API 向后兼容，不影响现有功能
- 使用 React Router 的动态路由传递书籍 ID
- 实现详情页的响应式设计，适配不同屏幕尺寸
- 使用 Toast 组件显示操作结果的提示信息
- 确保借阅和预约功能的权限控制
